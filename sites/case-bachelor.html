Overview

Designing
where nothing is forgiving.

The HMI display in a construction machine is nothing like a phone. It lives in direct sunlight. It's tapped through work gloves. The operator has been awake for 11 hours and still has two more to go. A misread number can cost a job, an injury, or a small fortune in fuel.

My bachelor thesis was a design system for these displays — a foundation Liebherr divisons could build the next generation of cab interfaces on.

  • Light and dark modes for every hour of the day at the construction site
  • Glove-friendly interaction targets
  • Hierarchical info architecture for fatigue states
  • Adjusted icons for optimal visibility and clarity

The Challenge

Fragmented interfaces, fractured experience

Across Liebherr's product segments, each subsidiary developed its own operator interfaces independently, resulting in inconsistent user experiences and limited collaboration on digital solutions.

  • No shared design system or styleguide for HMIs existed across subsidiaries
  • Existing corporate design guidelines were built for web and print, not machine displays
  • Interfaces varied widely in usability, icon language, and information architecture
  • Increasing relevance of assistance systems was not yet reflected in design standards

The Approach

From research
to reality

Following the Design Thinking process and the Double Diamond model, the project combined in-depth research with hands-on prototyping.

  • Conducted expert interviews across five Liebherr companies (concrete pumping, deep foundation, earthmoving, mining, tower cranes) plus the usability agency UID
  • Developed personas to represent designers, developers, crane operators, and technicians
  • Analyzed existing HMIs for strengths and weaknesses using a custom evaluation matrix
  • Built the design system in Figma, structured around grid, typography, color, icons, and reusable components following the Atomic Design principle
  • Defined light and dark mode color variables and a dedicated icon grid for consistent iconography
Outcome

Graded 1.1 —
A system built to scale

The result is a modular HMI design system that gives Liebherr's subsidiaries and external partners a shared foundation for building consistent, brand-aligned interfaces — from UI components and light/dark mode variables to a tested tower crane prototype validated through iterative user testing.

The thesis was awarded a grade of 1.1.
